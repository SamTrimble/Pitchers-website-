# Appendix A — Athlete Authentication and User Experience (Expanded)

## Athlete Authentication
- Individual athlete accounts
- Email/password login
- Google Sign-In (optional)
- Apple Sign-In (optional)
- Password reset
- Email verification
- Optional MFA
- Secure session management
- Audit logging

## Athlete Dashboard
After login the athlete sees:
- Today's workout
- Throwing program
- Arm Care assignment
- Readiness questionnaire
- Progress widgets
- Messages
- Recruiting status
- Upcoming events

## Athlete Permissions

Athletes CAN:
- Complete workouts
- Upload videos
- Message coaches
- View progress
- View recruiting milestones
- Update allowed profile fields

Athletes CANNOT:
- View other athletes
- Edit coach-only notes
- Edit verified testing
- Access billing admin
- View internal recruiting evaluations
